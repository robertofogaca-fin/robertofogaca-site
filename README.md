# robertofogaca.com.br

Site pessoal de Roberto Fogaça: contabilidade, tributário, regulatório BACEN, tesouraria e FP&A.

Tudo o que vai ao ar fica na pasta `public/`:

- `public/index.html`: página principal
- `public/publicacoes.html`: aba Publicações
- `public/publicacoes/`: um arquivo por artigo (`modelo-de-artigo.html` é o modelo)
- `public/assets/`: estilo e imagens
- `public/downloads/`: planilhas e materiais

`wrangler.jsonc` é a configuração do Cloudflare: não precisa mexer.

Como publicar um texto novo: veja `COMO-PUBLICAR.md`. Cada alteração salva neste repositório vai ao ar automaticamente pelo Cloudflare.
