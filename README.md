# robertofogaca.com.br

Site pessoal de Roberto Fogaça: contabilidade, tributário, regulatório BACEN, tesouraria e FP&A.

- `index.html`: página principal
- `publicacoes.html`: aba Publicações
- `publicacoes/`: um arquivo por artigo (`modelo-de-artigo.html` é o modelo)
- `assets/`: estilo e imagens
- `downloads/`: planilhas e materiais

Como publicar um texto novo: veja `COMO-PUBLICAR.md`. Cada alteração salva neste repositório vai ao ar automaticamente pelo Cloudflare Pages.
